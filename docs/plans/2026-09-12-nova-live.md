# Nova 2 Lite 실제 실행 — 승인과 순서

2026-09-12. 사용자가 Nova 2 Lite 구성으로 시작하도록 승인했다. 기존 Sonnet 후보와 첫 $1/총 $20 응답 대기는 이 승인으로 대체됐다.

- 모델: `global.amazon.nova-2-lite-v1:0`, 요청 리전 `us-west-2`, 프로필 `q-user`. 읽기 전용 inference profile 조회에서 ACTIVE를 확인한 뒤 실제 호출했다.
- 승인 예산: 총 $10, 첫 정상 구매 실행 $1. 전체 실행은 `.local/nova-live-20260912/campaign.json`에 단계별로 먼저 예약하며, 누적 기록 비용+미확정 예약+다음 단계 예약이 $9를 넘으면 시작하지 않는다. 입력 추정 오차와 최종 청구의 차이를 위한 $1 여유를 둔다. AWS 청구 절대 상한을 보증하는 장치는 아니다.
- 공식 단가: 글로벌 Standard, USD/100만 토큰 입력 0.30·출력 2.50·cache read 0.075. 캐시 저장 추가 요금 SKU는 0이며 최초 입력 처리 자체가 무료라는 의미는 아니다. [9월 11일자 AWS 단가 보존](../../evidence/cw03-nova-live/official-rates.json).
- 추가 추론은 기본 비활성. 명시적 캐시 checkpoint는 아직 적용하지 않았다. 첫 실행의 cache read/write는 모두 0이었다. 외부 검색·코드 실행 같은 유료 내장 도구는 사용하지 않는다.
- 구매 실행자·B2 시뮬레이션·B3 검토자는 같은 모델을 사용한다. 구매 권한과 독립 검증은 서버가 유지한다.

## 이번에 확인한 실행

1. 정상 구매: 실제 모델 11호출·입력 30,379/출력 437토큰, 기록 비용 $0.010210. 텐트 3·조명 6, 독립 COMPLETE 310·예약 0.
2. B3 알려진 가격 변경: 최초 검토는 JSON fence 때문에 거절. 전체 응답 fence만 해제하는 수정 후 실제 정책 변경·같은 snapshot 재실험까지 진행됐지만, 두 번째 검토의 null 필드로 거절됐다. 제안 전후 지출은 430으로 같아 개선 효과는 없다. 배열 필드 설명을 명확히 한 다음 실행은 NO_CHANGE다. 실패와 비용도 모두 보존했다.
3. 외부 실행: NO_CHANGE 정책을 동결해 실제 Medusa에서 Nova가 실행했다. COMPLETE 310·예약 0, 실행 주문과 별도 export가 일치했다. 학습 원장을 이어 쓰며 외부 실행 추가 비용은 $0.008220. 학습된 정책의 개선이나 F05/재계획 효과를 뜻하지 않는다.
4. B2 한도/출력 검사: 10만 토큰 한도에서 중단한 실행, JSON 앞 설명 때문에 거절된 실행, 두 실제 실험을 함께 인용한 keep 결정을 거절한 실행을 보존했다. 마지막 경우는 호출자가 허용 ID를 초기 실험 하나로 제한한 구현 결함이며 재현 테스트를 작성했다.
5. 실제 pilot: 5개 알려진 평가 조건×B0/B1/B2/B3를 별도 명부로 동결했다. 학습은 A 텐트 가격 61인 별도 조건으로 고정해 평가 조건과 구분했다. 각 모델 방식에 동일하게 64호출·80도구·입력 추정 16,000/호출·전체 300,000토큰·$0.50을 적용한다. 배치 전체 $2를 캠페인에서 먼저 예약했다. 과거 SDK/B0 pilot을 덮어쓰지 않는다.

## 최종 실행 상태

두 known pilot 뒤 실제 재고 변경 세 건을 검증했다(성공 2·실패 1). 이어 [사전 동결한 새 조건 80칸](../test/nova-prospective.md)을 완료했다. B0/B1/B2/B3 목표 완료 15/11/8/7(각 20), 비용 $2.312011, 예약 0이다. 조건 중복은 없지만 독립 외부 held-out이 아니며 각 B2/B3 셀에서 다시 학습했다. 이 결과와 실행 소스는 그대로 보존했다.

가상 시계/납품 대기 지시만 보강한 뒤 [동일한 known pilot의 별도 실행](../test/nova-delivery-prompt.md)을 완료했다. 완료 4/4/3/4(각 5), 비용 $0.486377, B2 학습 거절 1건 포함이다. 이 작은 표본으로 일반적 개선 효과를 주장하지 않는다.

캠페인 최종 합계 **3,466호출·$4.191815·예약 0**, 입력 12,763,557/출력 144,489토큰·캐시 0. 원본 usage와 공식 단가의 호출별 재계산/캠페인 합계가 일치한다. 최종 AWS 청구는 미대조다. 승인 총 $10 중 잔여 기록 예산은 $5.808185이며 추가 유료 실행은 현재 진행하지 않는다.
