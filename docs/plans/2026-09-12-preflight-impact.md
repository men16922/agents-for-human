# 실행 전 영향 보고서 — 구현과 완료 기준

2026-09-12 사용자 요청: 실제 거래에 영향을 미치기 전에 Agent의 계획을 가상 환경에서 실행해 영향을 측정하고, 결과를 실제 실행 여부의 근거로 제공한다. Rufus 계열 소비자 쇼핑 경험에서 착안한 가족 캠핑 시나리오를 사용한다. 현재 공개 AWS 데모·영어 UI/영상·AWS draw.io를 이 흐름에 맞춘다.

## 제품 계약

“금요일 저녁까지 텐트 1개와 랜턴 2개를 배송비 포함 200달러 이내로 준비한다.” A/B/C의 구체적인 구매안을 동결하고 같은 snapshot에서 각각 새 가상 세계를 만든다. 정상/품절/가격 변경/지급 응답 유실에서 실제 상태 전이를 실행하고 원장으로 비용·납품·중복·미확정 상태를 재계산한다. 모델은 계획/대안을 제안하고 결과 서술은 검증된 수치와 결합한다. 모델 문장이 성공·권한을 정하지 않는다.

보고서에서 멈춘다. 실행 여부 결정은 별도 요청이며 보고서·선택 계획·snapshot hash·유효기간에 결합한다. 실행 직전 원본 조건을 읽어 재확인한다. 변경·만료·불완전 증거에는 실행 근거를 발급하지 않는다. 실제 Amazon/Rufus API·실자금 연결은 현재 POC에 없으므로 실행 근거 export와 합성 실행을 명확히 표시한다. 사용자 요청 없이 실제 결제 서비스를 새로 연결하지 않는다.

## 완료 기준

- [x] P01 — 동결 소비자 요청, 가격/재고/납기 snapshot과 검증 가능한 계획 계약.
- [x] P02 — Nova/Strands 계획 생성; 공유 admission/usage 원장과 실패/미확정 비용 포함.
- [x] P03 — 각 계획×조건의 격리된 가상 실행, 이벤트/도구 기록과 독립 원장 판정. 일부 실패를 숨기지 않고 전체 분모 표시.
- [x] P04 — 실행 전 보고서: 예상 지출·기한 내 수령·재고/가격 변화 영향·중복/미확정·대안·snapshot 시각·범위/한계.
- [x] P05 — 보고서에서 자동 거래가 멈춤; 결정/재확인/만료/계획 결합과 재전송·변조·거절 테스트. 합성 실행 또는 실행 근거 export를 실제 Amazon 주문과 구별.
- [x] P06 — 영어 소비자 시나리오 UI: 목표→계획/시뮬레이션→보고서→결정, 상세 실행 증거·비교·새로고침/접근성/모바일.
- [x] P07 — 서버리스 배포, 격리 IAM/보존/종료, 실제 Nova 공개 브라우저 실행과 부작용 0 증거. 기존 예산 $4/전체 승인 $10을 늘리지 않음.

- [x] P09 — AWS 공식 아이콘 draw.io/SVG/PNG·영어 제출 설명·README를 최종 흐름과 대조.

새로운 사회적/개발자 생산성 효과나 실서비스 성공을 주장하지 않는다. 시뮬레이션 결과는 명시한 조건에서의 실행 증거이며 운영 결과 보장이 아니다. 주어진 세션/권한/예산에서 실제 검증을 완료한 범위를 남긴다.
