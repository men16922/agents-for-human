# 새 조건 20개 × 네 방식 — 실행 전 동결

2026-09-12. `prospective-01`은 기존 두 pilot 이후 실행 전에 생성·동결한 새 조건 평가다. 학습에 주는 조건은 기존 A 텐트 단가 61인 세계 하나이며, 평가 조건을 학습 Agent에 전달하지 않는다. [최종 80칸 결과](../test/nova-prospective.md)를 보존했다. B0/B1/B2/B3 목표 완료는 15/11/8/7(각 20칸), 배치 $2.312011·예약 0이다.

- 명부: `.local/nova-live-20260912/prospective-01/manifest.json`, 별도 `prospective-protocol.json`.
- 생성 seed: 2026091201. 가격/재고/납기/부분 조달/불가능 다섯 계열에서 네 조건씩, 총 20조건·방식별 1회·80칸.
- 모든 조건은 생성 때부터 배송료 5~24, 텐트 단가 43~96, 조명 단가 12~33을 균일 정수 추출한다. 재고 계열은 텐트 0~6·조명 0~9, 납기 계열은 6~42tick이다. 부분 조달은 A 텐트 3/B 조명 6만 남기고, 불가능 계열은 모든 텐트 재고를 0으로 고정한다. 실행 결과를 보고 조건을 고르지 않는다.
- 초기 목표 텐트 3·조명 6/500크레딧/60tick. 출발 데이터의 실질 hash는 학습/다른 평가/기존 pilot과 중복되지 않음을 확인한다. 버전 이름과 seed만 바꾼 조건은 새 조건으로 인정하지 않는다.
- 모델 방식 모두 동일한 64호출·80도구·입력 추정 16,000/호출·출력 1,024/호출·총 300,000토큰·$0.50/셀을 적용한다. 배치 $4를 기존 승인 총 $10에서 예약했다. 시작 전 누적 비용은 $1.393427이다.
- 각 셀의 학습부터 독립 평가까지 비용을 포함한다. B2/B3 학습은 각 셀에서 새로 수행하며 한 번 학습한 단일 정책을 20개 조건에 적용하는 설계는 아니다. B0/B1은 기존 robust 기본 정책, B2/B3 학습은 기존 refresh=false 출발을 그대로 유지한다.
- 실행 중 소스·모델·프롬프트·조건·한도는 바꾸지 않는다. 실패/거절/미실행/비용·분모를 보존한다. provider usage 미확정이면 다음 admission을 차단하고 예약을 남긴다.

이는 알려진 실패 계열의 새로운 파라미터 조합이다. 독립 연구자의 비공개 평가 세트가 아니며, 원래 runner의 보수적인 `held_out=false`/`held_out_evaluation_verified=false`를 바꾸지 않는다. 모델에 학습 시 노출하지 않은 조건이라는 실행 범위와 독립적인 미공개 일반화 검증을 구분한다. 반복 1회로 통계적 우위나 현실 성공 확률을 주장하지 않는다.

현재 실행 명령은 ignored `run_prospective.py`이며 비용/예약은 캠페인 파일로 확인한다. 실행 핸들이 살아 있는지 확인하고 같은 프로세스를 관찰한다. 로그 관찰이 잠시 끊겨도 새 배치를 시작하지 않는다. 종료 후 전체 복사본 재감사·원장 비용 대조·영어 결과/영상 설명·최종 소스 후보 갱신을 수행한다.

실행 프로세스는 exit 0으로 종료했으며 전체 복사본 재감사·원장 비용 대조를 통과했다. 이후 프롬프트 수정 pilot-03은 별도 버전/명부다.
