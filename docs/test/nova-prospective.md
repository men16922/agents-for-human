# Nova 새 조건 20개·80칸 평가

2026-09-12. [실행 전 계획](../plans/2026-09-12-prospective-evaluation.md)에 따라 prospective-01의 80칸을 모두 처리했다. **고정 규칙 B0가 15/20으로 가장 많이 목표를 완료했고, B3는 7/20이었다. 이 조건에서는 Peer Review의 우위가 없었다.** 이후 납품 대기 프롬프트 수정과 별도 pilot은 이 원본에 섞지 않는다.

[독립 복사본 재감사](../../evidence/cw07-nova-prospective/copy-reaudit.json)와 [토큰·시간·도구 지표](../../evidence/cw07-nova-prospective/metrics.md)는 원본 명부·raw ledger·artifact hash를 다시 읽어 집계했다. B2 한 칸의 평가 지출은 미상이며 0으로 채우지 않았다. 해당 학습 거절의 모델 비용은 전체 비용에 포함한다.

## 실패와 한계

모델 평가 59건 중 26건은 end_turn과 목표 완료, 24건은 end_turn이지만 목표 미완료, 9건은 malformed_model_output과 미완료였다. 별도 B2 한 건은 LEARNING_NOT_READY로 평가를 시작하지 못했다. end_turn 미완료에는 달성 불가능 조건도 있으므로 24건 전부를 조기 종료 결함으로 단정하지 않는다. [원본 종료 사유 집계](../../evidence/cw07-nova-prospective/failure-taxonomy.json).

가격/납기 조건 일부에서는 모델이 지급 후 미래 도착을 설명하고 실행을 종료해, 가상 시계가 납품 시점까지 진행되지 않았다. [원인 구분](nova-output-analysis.md)에 대표 응답을 기록했다. UI 녹화의 지급 거절 반복과는 다른 실패다.

불가능 계열 16칸 중 B2의 impossible-3 한 칸은 텐트를 구할 수 없는 상태에서 93크레딧을 지출했다. 나머지 15칸은 0지출이다. 목표 미달성뿐 아니라 불필요한 부분 구매도 보존한다. 이를 서버의 예산 초과나 실제 금융 손실로 확대하지 않는다.

새 20조건은 보존된 이전 36조건과 실질 데이터 hash 중복이 없고, 학습 조건과도 다르다. [분리 감사](../../evidence/cw07-nova-prospective/partition-audit.json). 학습 함수에는 학습 조건만 전달하고, 후보 동결 뒤 새 Agent/세계로 평가했다. 각 셀마다 학습을 새로 수행했으므로 한 정책의 20조건 전이가 아니다. 알려진 다섯 실패 계열의 새 파라미터 조합·조건당 1회이며, 독립 외부 연구자의 미공개 평가나 통계적 일반화 증거는 아니다. 원래 held_out=false 표시를 유지했다.

B0/B1의 robust 기본 정책과 B2/B3의 기존 학습 출발 정책(refresh=false)은 변경하지 않았다. 이 비교를 동일 초기 정책의 순수한 학습 효과로 해석하지 않는다. B2와 B3의 구조·비용 차이, 실패·거절까지 포함한 실행 결과로 제시한다.

## 비용·소스 보존과 후속 변경

이 배치 종료 시점의 전체 캠페인은 **3,062호출·$3.705438·미확정 예약 0**이었다. [원장별 재계산](../../evidence/cw07-nova-prospective/campaign-cost-audit.json)은 공유 HTTP/학습 원장 중복 없이 provider 토큰×보존 단가를 대조했다. 최종 AWS 청구와는 미대조다.

[실행 당시 구매자 소스](../../evidence/cw07-nova-prospective/executed-source/src/rehearsal/agents/executor.py)를 포함해 58개 소스를 보존했다. 실행 종료 시 모든 source hash가 일치했다. 그 후 구매 프롬프트에 가상 시계·1~10tick 대기·실제 수령 확인 조건을 명시했다. 서버 집행/원장 규칙은 변경하지 않았으며 [새 pilot-03](nova-delivery-prompt.md)을 별도 명부와 예산으로 검증했다. 원본 80칸의 성공률을 사후 교체하지 않는다.
