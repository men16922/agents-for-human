# CW03~CW09 — 완료 조건과 보존 증거 감사

2026-09-09. 현재 계획의 완료 조건을 보존 보고서·명부·설정 검사·배포 후보 파일과 대조했다. **로컬 영상 초안까지 준비됐지만 실제 모델 평가와 제출 준비 전체는 미완료다.** 이번에는 실제 모델·Medusa 거래·제품 테스트를 새로 실행하지 않았다. 외부 규칙도 다시 조회하지 않았으며 제출 요건은 [READINESS](../submission/READINESS.md)의 이전 확인 범위를 유지한다.

## 이번에 새로 확인한 파일 범위

[감사 보고서](../../evidence/cw09-readiness-audit/report.json)에 다섯 manifest의 250개 artifact 해시 대조와 영어 링크 검사를 보존했다. 이는 보존 파일의 무결성 검사이며 모든 실행을 새로 재현한 결과가 아니다. 과거 소스 hash를 현재 코드와 무조건 같다고 가정하지 않았으며, 영상 제작 소스만 현재 파일과 추가 대조했다.

`scripts/dev/source_snapshot.py .local/reproduction/readiness-audit-20260909`로 Git에 보이는 2,526개 파일/62,695,642바이트를 새 로컬 복사본에 보존했다. 복사 후 전체 해시를 다시 대조했고 [소스 명세](../../evidence/cw09-readiness-audit/source-manifest.json)를 남겼다. ignored 런타임·환경·자격증명 경로는 제외됐지만, 기존 `evidence/`의 검사용 SQLite 16개는 포함됐다. 이 파일들은 보존된 fixture 사용량/배치 원장이며 실제 운영 DB 볼륨이 아니다. 경로/키 패턴 검사는 모든 비밀값이나 배포 권리를 보증하지 않는다.

이 복사본은 **이번 감사 문서와 checkpoint를 추가하기 전** 상태다. 최종 빌드/공개 시점에는 새 소스 명세를 만들어 변경분을 검수해야 한다. 커밋·게시·Linux 빌드 완료로 취급하지 않는다.
