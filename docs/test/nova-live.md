# Nova 2 Lite — 실제 구매·검토·Medusa·pilot

2026-09-12. 사용자가 [Nova 글로벌/총 $10 구성](../plans/2026-09-12-nova-live.md)을 승인한 뒤 실제 Bedrock 호출을 시작했다. **실제 모델의 정상 구매와 별도 Medusa 거래를 확인했다. Peer Review의 성능 개선은 입증하지 못했다.** 비용은 원본 응답 사용량×보존 공식 단가의 합계이며 최종 AWS 청구 대조는 아니다.

## 정상 구매와 외부 거래

| 실행 | 결과 | 모델 사용량/비용 |
|---|---|---|
| 정상 연습 구매 | 독립 COMPLETE, 텐트 3·조명 6, 지출 310·예약 0 | 11호출, 입력 30,379·출력 437, $0.010210 |
| B3 가격 변경 후 외부 실행 | NO_CHANGE 정책을 동결, 실제 Medusa COMPLETE 310·예약 0. 실행 주문과 별도 export 일치 | 기존 학습 원장을 이어 사용, 외부 추가 비용 $0.008220 |

모델은 `global.amazon.nova-2-lite-v1:0`, 요청 리전은 `us-west-2`다. 추가 추론은 기본 비활성이고 명시적 캐시는 아직 설정하지 않았다. 서버·상품·크레딧은 로컬 합성 환경이다. 위 외부 거래는 실제 모델→구매 HTTP→Medusa/독립 판매자→별도 원장 검증이며 실제 금융 거래나 학습 효과를 뜻하지 않는다.

복사한 [외부 거래 증거](../../evidence/cw03-nova-live/http-session/evidence.json)와 [실행 기록](../../evidence/cw03-nova-live/http-execution/report.json)을 다시 대조한 [독립 판정](../../evidence/cw03-nova-live/copied-http-attestation.json)도 success=true, orders_match_execution=true다. 실행 보고서의 NOT_VERIFIED는 별도 판정을 요구하는 설계대로 보존했다.

## 실제 실행에서 확인한 문제

1. 첫 B3 검토 응답은 올바른 JSON을 Markdown fence로 감쌌다. 원본은 MALFORMED_REVIEW, fence만 제거하면 keep으로 재현됐다. 전체 응답이 단일 fence인 경우에만 포장을 제거하며 중복 필드·추가 객체·설명 문구·권한 필드 검사는 유지했다.
2. 다음 B3는 실제로 `refresh_quote_before_order: false → true`를 제안하고 같은 snapshot에서 재실험했다. 전후 모두 COMPLETE 430으로 지출 개선은 없었다. 두 번째 검토가 counterexamples=null을 반환해 전체 학습은 REJECTED로 남았다. 배열 필드를 명확히 한 다음 실행은 NO_CHANGE였으며 그 정책으로 외부 거래를 수행했다.
3. B2는 원래 공통 100,000토큰 한도에서 중단했다. 사용량 94,930토큰·기록 비용 $0.030594와 중단 분모를 보존했다. 다음 실행에서 입력 추정 한도를 16,000/호출, 전체를 300,000으로 올려 실제 필요량을 확인했다. 전체 USD 승인 예산은 바꾸지 않았다.
4. B2가 두 개의 실제 완료 실험을 함께 인용해 keep을 반환했지만, 호출자가 허용 ID를 초기 실험 하나로 제한해 거절했다. SDK 회귀에서 같은 실패를 재현한 뒤 keep에 한해 검증된 두 실험을 인용하도록 수정했다. revise는 계속 초기 정책의 실험만 인용해야 하고, 모르는 ID는 거절한다. 수정 후 별도 실제 B2 학습은 NO_CHANGE, 새로운 A 재고 부족 평가에서는 COMPLETE 380이었다($0.055093).

검토자가 keep을 선택하거나 후보가 더 낫지 않은 것은 성공적인 개선으로 바꾸지 않았다. 과거 실패 파일도 덮어쓰지 않았다. [실행 당시 소스](../../evidence/cw03-nova-live/executed-src/b2.py)와 수정 전 로그를 보존하며, 각 실행 소스 hash는 해당 시점의 버전을 가리킨다.

## 첫 동결 pilot — 수정 전 결과

기존 5개 알려진 조건을 사용해 새 명부를 만들었다. B2/B3 학습은 A 텐트 단가 61인 별도 조건이고, 모든 방식은 동일한 평가 조건을 받았다. B1/B2/B3에 64호출·80도구·입력 추정 16,000/호출·전체 300,000토큰·셀당 $0.50을 동일하게 적용했다. B2/B3의 학습·검토·평가 비용을 모두 포함한다. batch 예산 $2는 실행 전에 전체 캠페인에서 예약했다.

| 방식 | 계획 | 목표 완료 | 거절 | 평가 미완료 | 기록 모델 비용 |
|---|---:|---:|---:|---:|---:|
| B0 고정 규칙 | 5 | 4 | 0 | 1 | $0 |
| B1 단일 모델 | 5 | 3 | 0 | 2 | $0.068567 |
| B2 단일 모델+시뮬레이션 | 5 | 2 | 2 | 1 | $0.285712 |
| B3 시뮬레이션+Peer Review | 5 | 3 | 0 | 2 | $0.173490 |

20칸 모두 실행, 합계 $0.527769, 미확정 비용 예약 0이다. 각 방식에는 달성 불가능한 조건 한 개가 포함됐고 그 평가 지출은 모두 0이었다. B2 두 거절은 이후 수정한 인용 검사 결함이다. 가격 상승 조건의 B1/B3는 지급 380 뒤 수령 전 종료해 미완료다. 그 두 실행의 마지막 provider 사용량은 명시적 0/0으로 반환됐으며, 이것을 최종 AWS 청구 확인으로 해석하지 않는다. 이후 실행 보고서에는 provider 종료 사유도 별도로 보존한다.

[복사본 전체 재감사](../../evidence/cw03-nova-live/pilot-copy-reaudit.json)는 20개 분모·artifact·원본 사용량·판정을 다시 확인했다. 원래 SDK/B0 pilot의 NOT_RUN 셀은 그대로 남기며, 이번 결과를 그 파일에 덮어쓰지 않는다. 이 자료는 알려진 작은 pilot이고 미공개 평가나 통계적 효과 증거가 아니다.

## 수정 후 pilot과 비용 대조

같은 조건과 한도의 별도 pilot-02도 20칸 모두 종료했다. [복사본 독립 재감사](../../evidence/cw03-nova-live/pilot-02-copy-reaudit.json)와 [전체 지표](../../evidence/cw03-nova-live/pilot-02-metrics.json)를 보존했다. 첫 pilot과 버전을 섞어 성공률을 계산하지 않는다.

| 방식 | 목표 완료/전체 | 평가 미완료 | 기록 모델 비용 |
|---|---:|---:|---:|
| B0 고정 규칙 | 4/5 | 1 | $0 |
| B1 단일 모델 | 3/5 | 2 | $0.092444 |
| B2 단일 모델+시뮬레이션 | 3/5 | 2 | $0.280186 |
| B3 시뮬레이션+Peer Review | 4/5 | 1 | $0.142691 |

합계 $0.515321, 거절 0·미확정 예약 0이다. 달성 불가능 조건은 네 방식 모두 지출 0이다. 그 외 B2 가격 상승/B1 부분 조달은 각각 380/390 지급 뒤 수령을 완료하지 못했으며 provider 종료 사유는 `malformed_model_output`이었다. 실패는 그대로 분모에 포함했다. 작은 알려진 표본의 B3 4/5는 B0와 같으며 Peer Review의 인과적 효과나 통계적 우위로 해석하지 않는다.

전체 캠페인은 **1,069회 호출·입력 3,879,635/출력 44,488토큰·기록 비용 $1.275584**, 미확정 예약 0이다. [48개 원장 비용 감사](../../evidence/cw03-nova-live/cost-audit.json)는 공유 학습/HTTP 원장을 중복 합산하지 않고 매 호출 단가를 다시 계산해 캠페인 합계와 대조했다. cache read/write는 모두 0이고 최종 AWS 청구는 미대조다. 승인 $10, 신규 단계 admission 기준 $9는 그대로 유지한다.

수정 회귀 128개와 전체 `make check`(Python 690·mypy 58·lint·lock·웹 빌드)를 통과했다. [최종 gate 로그](../../evidence/cw03-nova-live/final-gate.log)와 [artifact 해시](../../evidence/cw03-nova-live/artifact-manifest.json)를 보존했다. 기존 컨테이너 4개·볼륨 50개를 보존하고 개발 포트 6개를 반환했다. 이번에는 새 브라우저 gate를 실행하지 않았다.

## 남은 작업

실제 모델의 F05는 pilot의 한 개 알려진 설명 조건 범위다. 모델의 이벤트 기반 재계획·미공개 20조건 평가·사람의 관찰·실제 모델 영상·독립 호스트·공개 제출은 별도 작업이다. 기존 영상과 관측 UI 시연은 여전히 SDK 구매자 녹화이며 실제 Nova 영상으로 표시하지 않는다.
