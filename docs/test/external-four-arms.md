# 네 비교 방식의 외부 실행과 공통 회계

2026-09-09. [외부 사전 명부·정산](external-comparison-budget.md)에 B0/B1/B2를 연결했다. B0는 고정 규칙, B1은 단일 구매 Agent, B2는 단일 Agent 학습 후 구매, B3는 독립 검토를 포함한 학습 후 구매다. 실제 로컬 Medusa에서 각각 새 세션으로 실행했으며, 모델 역할에는 SDK fixture를 사용했다.

## 구현과 경계

`BudgetCarryover`가 방식별 원래 usage DB와 동결 artifact를 검증한다. B0/B1은 NOT_REQUIRED 보고서와 빈 사용량 원장을 준비하며 학습 모델 factory를 호출하지 않는다. B2는 원래 단일 Agent 학습 원장을 이어 쓰고 Reviewer를 추가하지 않는다. B3의 기존 호출 방식은 호환 alias로 유지했다.

외부 HTTP 실행 명세에는 방식과 실행자 종류를 기록한다. B0는 모델 인자가 없어야 하며 다른 방식에는 모델이 필요하다. 이를 서로 바꾸면 구매 전에 거절한다. B0의 고정 규칙 실행자도 같은 구매 HTTP·기대 run/목표/예산 검사·도구 admission 원장을 사용한다. 모델 호출은 0회이지만 도구 호출을 한도에서 제외하지 않는다. B0는 전체 배치의 모델 비용 예약을 0으로 유지한다.

각 방식의 학습·외부 실행은 원래 비용/토큰/호출/도구 한도를 공유한다. 특히 B2 학습 후 호출·토큰·비용 상한이 부족하거나 도구 한도가 소진되면 외부 구매를 거절한다. 실행 완료는 여전히 NOT_VERIFIED이며 별도 export·주문/원장 검증이 필요하다. 사용량 누락·중단·예약 보존과 전체 분모의 규칙은 그대로다.

## 실제 Medusa 검사

`make commerce`를 기동한 뒤 `make external-arms-smoke`를 수행했다. 명부의 한 조건 × 네 방식을 실행 전에 고정했고 각 방식에 새 고객/run·정책·원장을 사용했다. 공급처 grid를 실제 Medusa에 적용하는 검사는 이번에도 수행하지 않았으며 조건 일치 수는 **0**이다.

이 표는 모델 성능 비교가 아니다. 선언한 공급처 grid와 실제 Medusa 초기 조건의 일치는 미검증이며 실제 기본 환경에서 거래가 완료됐다는 증거다. B0/B1의 초기 정책과 B2/B3의 학습 초기 정책도 같지 않다. 같은 초기 정책·미공개 조건·누출 통제·반복을 갖춘 본 평가와 Peer Review 효과는 별도로 검증해야 한다.

[보존 증거](../../evidence/cw07-external-arms/artifact-manifest.json)는 93개 artifact와 별도 manifest다. 명부 SQLite·네 실행/학습·원시 export·단계별 전체 집계·세션/초기 HTTP를 보존했다. 복사 명부를 재집계하고 네 거래와 B2/B3의 학습 원장 4개를 독립 재판정했다. 소스 48개 hash·비밀값 미포함도 확인했다. 포트 18001/19000/55432/56379를 반환했고 기존 컨테이너 4개·볼륨 2개를 보존했다.

## 회귀와 재개

추가 회귀 13개는 방식별 준비/학습 역할·합산 사용량·독립 판정, B0/모델 실행 모드 교체 거절, B0 도구 상한·주문 전 scope 재확인, B2의 네 가지 공통 한도 소진을 검사한다. 외부 배치 회귀는 기존 포함 29개다. B0의 원장/지급 GET을 보존된 실제 응답으로 replay하도록 HTTP fixture도 확장했다.

`make check`: Python 470개·mypy 48소스·ruff·lock·웹 빌드 통과. 기존 TestClient 경고 2개 유지. 브라우저·실제 모델·AWS·설치·배포·커밋·푸시는 수행하지 않았다.

실제 모델 설정 후에는 [외부 배치 명령](external-comparison-budget.md)의 `--cell`에 B0/B1/B2/B3 칸을 지정한다. `--learn`은 B0/B1에서는 무학습 준비만 수행하고, B2/B3에서는 실제 학습을 수행한다. B0의 `--execute`는 Bedrock 모델을 생성하지 않는다. 다른 방식은 동일한 동결 설정을 확인한 뒤 모델을 생성한다. 명부 준비 자체는 모델 호출이 아니다.

후속 [정적 초기 조건 검사](static-initial-conditions.md)에서 공급처 가격·재고·배송비·납기 설정 적용과 실행 전 원시 관측 대조를 실제 Medusa 5건으로 검증했다. 이 문서의 이전 실행 4건은 조건 증거가 없어 계속 미검증이다. 실행 중 이벤트 조건·실제 모델·동등 초기 정책·미공개 비교는 남았다.
