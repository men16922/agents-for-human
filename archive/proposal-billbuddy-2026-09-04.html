문제 정의

매달 반복되는 청구서 확인, 납부, 지출 분석을 사람이 일일이 하고 있습니다. 깜빡하면 연체, 이상 금액을 놓치면 손해.

BillBuddy는 이 모든 것을 AI 에이전트가 자율 처리하고, 진짜 판단이 필요한 순간에만 사용자를 찾습니다.

Sim2Real 전략

시뮬레이션에서 검증하고, 그림자로 관찰하고, 실전에 투입한다

왜 Sim2Real인가?

금융 에이전트는 실수하면 돈이 날아갑니다. 로보어드바이저가 백테스팅을 거치듯, AI 에이전트도 시뮬레이션에서 충분히 검증한 후 실전에 투입해야 합니다.

Shadow Mode 상세

  • 실제 청구서 감시 + 가상 결제
    에이전트가 실제 이메일을 파싱하되, 결제는 시뮬레이션으로만 실행. "이번 달이었으면 USDT로 45,000원 결제했을 겁니다 (수수료 0.3%)"
  • 성과 리포트 자동 생성
    Shadow 기간 동안의 판단 정확도, 예상 절감액, 연체 방지 건수를 월간 리포트로 제공
  • 사용자 신뢰 → Real 전환
    N개월간 Shadow 결과를 확인한 뒤, 사용자가 직접 Real 모드 활성화. 자율 결제 한도도 점진적으로 설정

개선 아키텍처 (Strands SDK)

핵심 변경점

  • AgentCore Harness → Strands Agents SDK + AgentCore Runtime
    해커톤 필수 요건. @tool 데코레이터로 도구 정의, 내장 observability, multi-agent 구조
  • Single Agent → Multi-Agent (Coordinator + 3 Sub-agents)
    Coordinator가 의도 분류 후 전문 에이전트에 위임. 각 에이전트가 독립적 판단
  • EventBridge 스케줄러 추가
    매일 09:00 자동 실행 → Bill Monitor Agent가 마감 임박 건 감지 → SNS 알림

"알아서 하고, 필요할 때만 물어보는" Everyday Agent

현재 vs 개선: 반응형 → 자율형

현재 (반응형 챗봇)개선 (자율 에이전트)
"이번 달 청구서 알려줘" → 목록 반환 매일 자동 스캔 → 3일 내 마감 건 푸시 알림
"코인으로 결제해줘" → 수동 실행 설정 금액 이하 자동 결제, 초과 시만 승인 요청
"이상한 거 있어?" → 수동 분석 새 청구서 등록 시 자동 비교 → 이상 시 즉시 알림
사용자가 탭 전환해서 확인 일간/주간/월간 자동 리포트 이메일 발송

Human-in-the-Loop 의사결정

에이전트의 자율 실행 레벨을 사용자가 설정합니다. "5만원 이하는 자동 결제, 이상은 물어봐줘" — 로보어드바이저의 위임 한도와 동일한 개념.

의사결정 흐름

학습 루프

  • 승인 패턴 학습
    "여름 전기요금 상승은 정상" → Memory 저장 → 다음 여름에는 자동 결제
  • 거부 패턴 학습
    "이 구독 해지할 거야" → 다음 달 자동결제 보류 + 해지 리마인드
  • 자율 레벨 점진적 확대
    Shadow 3개월 → 5만원 한도 → 10만원 한도 → 전체 위임. 사용자 신뢰에 비례
Everyday Agents 트랙 핵심: "work in the background, make the safe calls on their own and surface only when a human actually needs to weigh in" — BillBuddy는 이 철학을 Sim2Real + Shadow Mode로 안전하게 구현합니다.

킬러 데모 시나리오

심사위원 앞에서 5분 안에 보여줄 핵심 흐름 — "이 에이전트는 알아서 합니다"를 증명
  • 1. 로그인 즉시 자동 브리핑
    "안녕하세요! 오늘 마감인 청구서 2건, 이상 금액 1건 감지했습니다. 자동 결제 1건 완료했습니다."
  • 2. 이상 탐지 → 판단 요청
    "전기요금이 전월 대비 45% 올랐습니다 (95,000원→137,000원). 자동결제를 보류했습니다. 결제할까요?"
  • 3. 사용자 승인 → 학습
    "여름이라 에어컨 때문이야, 결제해" → 에이전트: "USDT 32.5개로 결제 완료. 6-8월 전기요금 상승은 정상 패턴으로 기억하겠습니다."
  • 4. Shadow Mode 리포트
    "지난 3개월 Shadow 결과: 판단 정확도 94%, 연체 방지 7건, 예상 절감 12,000원. Real 모드로 전환하시겠습니까?"
  • 5. 코인 최적 결제
    "AWS 비용 $47.23을 결제합니다. 현재 BTC보다 USDT 결제가 수수료 0.2% 절감됩니다. USDT로 진행할까요?"
