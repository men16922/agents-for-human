## Title

Rehearsal — Live AI Purchasing Demo | Amazon Nova 2 Lite on AWS

## Description

Can an AI purchasing agent still deliver when stock disappears? This 2:30 walkthrough operates the deployed Rehearsal dashboard in visible Google Chrome.

Try the demo: https://d1u9yhii3gor6j.cloudfront.net

We select B3 peer review, choose Stock disappears, and run a real AWS experiment. The agent practices, an independent reviewer checks the policy, and Nova buys from supplier B. The journal verifies 3 tents and 6 lights delivered for 380 synthetic credits, with no unresolved payment reservation. All 23 model calls across practice, review and buying cost an estimated $0.023002. The reviewer kept the existing policy (NO_CHANGE); this demonstration does not establish a peer-review advantage.

The edited walkthrough uses actual Chrome footage, cropped to relevant panels. Recorded motion stays at original speed. Brief held frames are labeled. English narration and captions accompany the experiment, transaction timeline, refresh and AWS architecture.
