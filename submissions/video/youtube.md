Title: Rehearsal — See an AI Agent’s Impact Before It Acts | AWS + Nova 2

## Description

Before a shopping agent places an order, Rehearsal executes its plan in isolated virtual worlds and presents the evidence for a human decision.

This real Google Chrome walkthrough uses the deployed AWS application and Amazon Nova 2 Lite. The scenario is a family camping trip: one tent and two lanterns, delivered by Friday evening, under $200 including shipping. Nova proposes A; twelve verified runs reveal the tradeoffs and recommend B for review. We inspect payment-response uncertainty, accept a bound execution brief, download evidence and reload the decision.

All commerce is synthetic. The preview creates no external order, has no Amazon/Rufus connector and does not authorize real payments. Stock and price changes target A; these tests are not real-world success probabilities.

Live demo: https://d1u9yhii3gor6j.cloudfront.net
Built with Strands Agents SDK, Amazon Nova 2 Lite, Bedrock AgentCore, Lambda, DynamoDB, S3, Step Functions, API Gateway, CloudFront, React and TypeScript. English narration: ElevenLabs Daniel.
